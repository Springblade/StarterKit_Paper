Added a labelled native status dropdown to the authenticated payment history page. It submits via GET, keeps valid selections in the URL, and filters only the current user’s orders while preserving newest-first ordering. Invalid, empty, or repeated `status` parameters show all orders. A filtered empty result includes a link to all statuses.
